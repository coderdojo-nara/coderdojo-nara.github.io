# Courier — GAS 受け口

Courier のバックエンド（Google Apps Script Web App）。フォーム送信を受け取り、
**スプレッドシートに記録（＝確定点）**し、**通知メール（best-effort）**を送る。

配布モデルは「コピーして使う」。記録先スプレッドシートに**コンテナバインド**で
このスクリプトを載せて使う（スプレッドシートIDをコードに直書きしない）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.gs` | エントリポイント（`doGet` / `doPost`）。薄く保つ |
| `config.gs` | `FORM_DEFINITIONS`（種別定義）と設定の読み取り |
| `service_submission.gs` | 送信 1 件の処理（検証 → 記録 → 通知 → 状態書き戻し） |
| `repo_sheet.gs` | シート読み書き（排他制御・ヘッダー名で列解決） |
| `service_mail.gs` | 通知メール送信（best-effort） |
| `util.gs` | 汎用ヘルパー（JST 日時・テンプレート差し込み） |
| `appsscript.json` | デプロイ設定（`timeZone: Asia/Tokyo` / 匿名アクセス） |

## 設定値の置き場所（併用方針）

- **スクリプトプロパティ**（開発者が設定・秘匿値）: 通知先メール、Discord URL 等
  - 例: `NOTIFY_EMAIL`, `SPREADSHEET_ID`（コンテナバインドでない場合のみ）
- **`_config` シート**（運用者が触る値）: シート名・通知メール文面など（無ければ定義のフォールバック）

> 具体的なキー名・手順は段階3（GAS 実装）で確定させてここに追記する。

## デプロイ手順（詳細は段階6で整備）

1. 記録先スプレッドシートを作成。
2. 拡張機能 → Apps Script でコンテナバインドのスクリプトを開く（または clasp で push）。
3. 本フォルダの `*.gs` / `appsscript.json` を配置。
4. スクリプトプロパティに設定値を登録。
5. 「ウェブアプリ」としてデプロイ（実行: 自分 / アクセス: 全員）。`/exec` URL を控える。
6. `doGet` 疎通確認 → フォームからテスト送信で追記・メールを確認。
