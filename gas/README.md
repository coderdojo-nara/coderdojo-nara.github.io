# Courier — GAS 受け口

Courier のバックエンド（Google Apps Script Web App）。フォーム送信を受け取り、
**スプレッドシートに記録（＝確定点）**し、**通知メール（best-effort）**を送る。

配布モデルは「コピーして使う」。記録先スプレッドシートに**コンテナバインド**で
このスクリプトを載せて使う（スプレッドシートIDをコードに直書きしない）。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.gs` | エントリポイント（`doGet` / `doPost`）。薄く保つ |
| `config.gs` | `FORM_DEFINITIONS`（種別定義）と設定の読み取り |
| `service_submission.gs` | 送信 1 件の処理（検証 → 記録 → 通知 → 状態書き戻し） |
| `repo_sheet.gs` | シート読み書き（排他制御・ヘッダー名で列解決） |
| `service_mail.gs` | 通知メール送信（best-effort） |
| `util.gs` | 汎用ヘルパー（JST 日時・テンプレート差し込み） |
| `appsscript.json` | デプロイ設定（`timeZone: Asia/Tokyo` / 匿名アクセス） |

## 設定値の置き場所（併用方針）

- **スクリプトプロパティ**（開発者が設定・秘匿値）: 通知先メール、Discord URL 等
  - 例: `NOTIFY_EMAIL`, `SPREADSHEET_ID`（コンテナバインドでない場合のみ）
- **`_config` シート**（運用者が触る値）: シート名・通知メール文面など（無ければ定義のフォールバック）

## 記録先スプレッドシートの指定

フォーム種別ごとに `config.gs` の `FORM_DEFINITIONS` で指定できる。

```javascript
const FORM_DEFINITIONS = {
  contact: {
    // ブラウザのアドレスバーの URL をそのまま貼る（空なら下記フォールバック）
    spreadsheetUrl: 'https://docs.google.com/spreadsheets/d/XXXX/edit',
    sheetName: 'お問い合わせ',
    // ...
  },
};
```

解決順序:

1. フォーム定義の `spreadsheetUrl`（フォームごとに記録先を変えられる）
2. スクリプトプロパティ `SPREADSHEET_ID`
3. コンテナバインドのアクティブなスプレッドシート

注意: `spreadsheetUrl` で別のスプレッドシートを指定する場合、**デプロイ実行アカウント
（「自分として実行」の自分）にそのスプレッドシートの編集権限**が必要。
`_config` シートは従来どおりスクリプト自身のスプレッドシート（2 → 3 で解決）から読む。

## 各チャンネルは独立した設定（設定があるものだけ処理する）

| チャンネル | 設定 | 未設定時 |
| --- | --- | --- |
| スプレッドシート記録 | 上記の解決順序（1〜3） | スキップ（エラーにしない） |
| 通知メール | `NOTIFY_EMAIL`（プロパティ / `_config`） | スキップ（エラーにしない） |
| 自動返信メール | フォーム定義の `notify.autoReply` | スキップ |
| Discord 通知 | フロント側（Courier.astro の `discordWebhookUrl`） | フロントがスキップ。GAS は関与しない |

成功（`ok: true`）の判定:

- **記録が設定されている場合**: 記録の成功＝確定点（従来どおり）。メールは best-effort で、
  結果はシートの状態列に書き戻す。
- **記録が未設定の場合**: メールが確定点。メールも失敗したら `ok: false`（内容がどこにも
  残らないため、成功と偽らず再送を促す）。
- **記録・メールとも未設定の場合**: `ok: true`（GAS 側の処理なし＝成功扱い。
  自動返信は独立した設定なので、`notify.autoReply` があればこの場合でも送られる）。

注意: 記録が未設定の場合、送信ID による冪等判定（再送時の二重通知防止）は働かない。
また「設定があるのに使えない」（URL誤り・権限不足など）はスキップではなくエラーとして返す。

> 具体的なキー名・手順は段階3（GAS 実装）で確定させてここに追記する。

## デプロイ手順（詳細は段階6で整備）

1. 記録先スプレッドシートを作成。
2. 拡張機能 → Apps Script でコンテナバインドのスクリプトを開く（または clasp で push）。
3. 本フォルダの `*.gs` / `appsscript.json` を配置。
4. スクリプトプロパティに設定値を登録。
5. 「ウェブアプリ」としてデプロイ（実行: 自分 / アクセス: 全員）。`/exec` URL を控える。
6. `doGet` 疎通確認 → フォームからテスト送信で追記・メールを確認。
